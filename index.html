3. Tested SQL Operations

Relational SELECT Query (JOINs)

SELECT 
    p.post_id,
    u.username AS creator,
    p.caption,
    p.location
FROM posts p
JOIN users u ON p.user_id = u.user_id
ORDER BY p.created_at DESC;

Aggregate Functions Query

SELECT 
    p.user_id,
    u.username,
    COUNT(l.user_id) AS likes_count
FROM posts p
JOIN users u ON p.user_id = u.user_id
LEFT JOIN likes l ON p.post_id = l.post_id
GROUP BY p.user_id, u.username
ORDER BY likes_count DESC;

4. Viva Evaluation Cheat Sheet

Q: Why use a Composite Primary Key in `followers`?

PRIMARY KEY (follower_id, following_id) enforces uniqueness at the database level so a user can never follow the exact same account twice.

Q: How is data integrity handled on user deletion?

We use ON DELETE CASCADE on foreign keys. Deleting a user automatically purges their posts, comments, likes, and follower relationships.

Q: What does the aggregate query compute?

It groups posts by creator using GROUP BY and computes total likes using COUNT(), handling posts with 0 likes via LEFT JOIN.
